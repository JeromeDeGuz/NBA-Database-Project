## Makefile Commands: 

### Running the Database:

Using the native command line terminal run the command, 
to build and run the database.
```bash
make msql
```

### Cleaning up Database:

Using the native command line terminal run the command, 
to clean up the files created from building the database.
```bash
make clean
```
